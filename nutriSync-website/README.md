# Next.js Application with Tailwind CSS, TypeScript, and ShadCN

This project is a Next.js application that utilizes Tailwind CSS for styling, TypeScript for type safety, and ShadCN for component design.

## Getting Started

To get started with this project, follow the instructions below.

### Prerequisites

Make sure you have the following installed:

- Node.js (version 14 or later)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd nextjs-app
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```

   or

   ```bash
   yarn install
   ```

### Running the Application

To run the application in development mode, use the following command:

```bash
npm run dev
```

or

```bash
yarn dev
```

The application will be available at `http://localhost:3000`.

### Building for Production

To build the application for production, run:

```bash
npm run build
```

or

```bash
yarn build
```

Then, you can start the production server with:

```bash
npm start
```

or

```bash
yarn start
```

### Usage

This application is structured to allow for easy development and scalability. You can find reusable UI components in the `src/components/ui` directory and shared components in the `src/components/shared` directory.
